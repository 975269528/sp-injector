上游池 (每个上游绑定自己的 Key + 模型列表)

每个上游绑定自己的 API Key(转发时用此 Key 认证)。点「拉取」自动调用该上游的 /models 端点获取支持的模型列表(OpenAI 兼容协议);拉取失败可手动编辑。

模型映射 (客户端 model 名 → 指定上游 + 真实模型名,精确匹配)

客户端发的 model 精确等于「客户端名」即命中。每条映射可单独设置注入模式(留空则用全局模式)。每条映射可配多个候选上游,按顺序逐个尝试,连接失败/401/403/429/5xx 自动切下一个。「真实模型名」填写后转发时把请求体 model 改写成它;留空则原样转发。拖拽把手调整候选顺序。未命中的请求会被拒绝(需先配映射)。
