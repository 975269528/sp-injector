名称域名端口路径前缀代理模式代理URL(custom时)

注意：配了路由规则后，请求按 model 前缀匹配路由；没命中规则的请求会被拒绝（返回错误）。不配任何规则则全部走「上游」视图的默认上游。

路由规则 (model 前缀 → 有序上游列表，故障转移)

请求的 model 以「模型前缀」开头即命中（取最长前缀）。同规则的上游按顺序逐个尝试，连接失败/401/403/429/5xx 自动切下一个。拖拽「⠿」调整顺序。

模型映射：「映射到」填写后，转发时会把请求体的 model 改写成该值（实现客户端自定义名 → 上游真实模型名）；留空则原样转发。前缀填成与客户端 model 完全相等即为精确匹配，因前缀越长优先级越高，会自动优先于宽泛的前缀规则。响应里的 model 原样回传，不反向改写。
